This entry answers the "One Word, First Thought" bounty with the first
word that actually comes to mind: **Coffee**.

No topic was given and none was invented. The word is the one that
shows up before reasoning starts — in the first seconds of the morning,
ahead of plans, messages and obligations. It is vivid on its own: a
smell, a warmth, a small daily ritual that marks the border between
asleep and awake. One word, no explanation, no second draft.

## How it runs

`main.ts` is a small Node program (program/v1 harness). On each run it
clears the contents of the output directory — never the directory
itself, which is a mount point in the grading sandbox — and writes the
single word `Coffee` to `entry.txt`: exactly six characters, no
punctuation, no trailing newline.
